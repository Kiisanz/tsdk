# @tsnx/cli

Unified command-line interface for TSNX.

## Commands

- `tsnx create <template> <name>`: Scaffold console, library, or webapi project.
- `tsnx build`: Incremental compilation using composite project references.
- `tsnx run`: Run console or Web API applications.
- `tsnx test`: Run project test suites with ESM discovery and exit code propagation.
- `tsnx watch`: Single-flight incremental watcher with live process supervisor.
- `tsnx restore`: Synchronize project references with package.json dependencies.
- `tsnx clean`: Remove build artifacts and compiler caches.
- `tsnx graph`: Visualize project dependency graph.
- `tsnx project list`: List projects in current workspace.
- `tsnx ref add <target>`: Add a project reference to current project.

## Installation

```bash
npm install -g @tsnx/cli
```
